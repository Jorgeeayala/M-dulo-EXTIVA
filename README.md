# ⚡ Marangatu Pro - Extensión de Chrome

## 📦 Instalación

1. `chrome://extensions/`
2. Modo de desarrollador ON
3. Cargar carpeta `extension/`
4. **Habilitar popups** para marangatu.set.gov.py
5. Click en ⚡

## 🚀 Uso

1. Click en icono ⚡
2. Login con tu RUC
3. Click "Formularios IVA"
4. Selecciona períodos (1, 3, 6 meses o personalizado)
5. Click "Descargar formularios"
6. ¡Espera y listo!

## 🔍 Debug

Si algo falla, presiona **F12** y ve a la pestaña **Console**.

Verás logs detallados de cada paso:
```
[Marangatu Pro] 🔍 Buscando menú Consultas...
[Marangatu Pro] ✅ Encontrado menú Consultas
[Marangatu Pro] 👆 Haciendo click...
```

---

## ⚙️ Configuración

En la extensión:
- **Delay**: Segundos entre descargas (1-10)
- **Prefijo**: Nombre de archivos (IVA, FORM, etc.)
